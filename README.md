# Toms Tools

A small React + Vite web app with two tools:

- **Budget** — track income and expenses, see totals and a spending-by-category chart.
- **Scrum Board** — a drag-and-drop Kanban board (Backlog / To Do / In Progress / Done) with hours per card and a chart of remaining backlog hours over time.

All data is stored locally in the browser (`localStorage`) — no backend required.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
